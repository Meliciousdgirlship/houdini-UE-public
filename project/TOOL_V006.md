# 新版 UE 工具面板

## 紧凑布局更新

修复了下拉菜单选项未持久化的问题，改为打开时填充。设计参数、生成按钮、固定高度 AI 输入框和 AI 按钮集中排列；尺寸覆盖、种子及 API 说明默认折叠。当前已打开的面板可在 UE Python 输入 `import building_tool_layout; building_tool_layout.refresh()` 直接更新，无需重启或重新输入密钥。重启后自动使用更新布局。

资产：`/Game/landscape/Houdini/EUW_MedievalBuildingTool_V006`。

当前已打开的 UE：关闭旧面板，在输出日志切换 Python，运行：

```python
import building_tool_v006; building_tool_v006.open_tool()
```

以后重启项目，可右键新版资产 → 运行编辑器工具控件；项目启动脚本会自动初始化。

## 所有建筑参数

- 七项设计：用途、规模、高矮比例、附楼布局、屋顶、配色、装饰密度。
- 每项提供 AI 锁定。手动调整不受 AI 锁定限制；锁定选项不等于锁定全部派生几何。
- 高级尺寸覆盖：宽度 5–18 米、长度 4–12 米、楼层整数 1–3、层高 2.4–3.4 米、屋顶高度 1.2–6 米、屋檐伸出 0.25–0.8 米。
- 勾选“覆盖”才使用该输入；否则规则自动推导。切换规模时，已勾选的尺寸覆盖优先。
- 变化种子整数 0–99999；相同种子使细节稳定。
- 平屋顶已隐藏。连桥需要至少两层，显式一层覆盖会提示错误。

先选场景建筑或内容浏览器网格，点击“读取选中建筑”。目标会固定显示在面板顶部；切换目标时再次点击读取。手动生成与 AI 生成共用面板当前完整参数；AI 成功后回填新值。AI 生成期间锁定参数、接口和目标选择。状态栏显示失败原因。

## AI 接口注释

面板可编辑 Base URL、模型 ID，保存到本机 api.local.json（不提交 Git）。点击配置密钥打开隐藏输入窗口，密钥存在用户环境变量。配置完成可刷新状态，不展示密钥。

客户端 POST 到 /chat/completions，使用 Bearer 认证，非流式返回。发送面板设计 JSON 与描述文字，不发送建筑网格。每次 AI 生成可能消耗平台额度，完成后直接应用；没有预览确认步骤。HTTP 错误解释已写在界面中。

BUILDING_API_BASE_URL 和 BUILDING_API_MODEL 环境变量优先于面板配置；BUILDING_API_KEY 为密钥，兼容旧 CLAUDEX_API_KEY。当前默认沿用用户原平台和模型，不保证账户拥有模型权限。

同一资产的全部场景实例会更新。结果需要保存资产。工具不会更新当前打开的 Houdini GUI 会话。AI 在线调用和 UE 工具接口已完成；UE 工具资产保留在原 Te08 项目。
