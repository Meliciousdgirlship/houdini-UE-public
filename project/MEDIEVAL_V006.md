# v006 六栋建筑分别设计

打开 building_generator_v006_medieval_town.hipnc，在 /obj 选对应节点，P 查看七项设计控制。

| 建筑 | 形状 | 装饰与物件 |
| --- | --- | --- |
| 旅馆 | 较宽主楼、二层阳台 | 双烟囱帽、酒杯招牌、圆桌、长凳、杯子 |
| 住宅 | 窄小高坡屋顶、凸窗 | 花盆花朵、短篱笆、扫帚 |
| 商店 | 窄深体量、高坡屋顶、长条纹棚 | 货筐、果蔬、木箱、粉笔价目板 |
| 铁匠铺 | 宽矮石屋、低坡顶、工作棚 | 铁砧、炉灶、锤子、铁锭、铁料、淬火桶 |
| 公会馆 | 宽大主楼、塔楼连桥、屋脊钟亭 | 盾徽、柱础、仪式铺毯、修剪绿植 |
| 守卫所 | 紧凑石屋、窄窗、扶壁、塔楼垛口 | 盾徽、武器架、长矛、火盆 |

用途会影响默认体量与屋顶比例；显式尺寸覆盖仍优先。附加物位置跟随建筑尺寸。装饰密度控制部分生活物件，标志性结构保留。旧版对角木梁调整到窗下区域，减少遮挡窗户。

UE 目录为 /Game/landscape/Houdini/MedievalTownV006，六栋作为独立静态网格导入。选择资产后桥接脚本读取各自源 OBJ/spec；本机默认 HIP 改为 v006。已经开启的 UE 保存工作后重启，以加载新 Python 模块。

当前是外观模型和基础色材质；物件属于各建筑网格的组成部分，未拆成可交互道具。没有可通行室内、最终纹理或角色碰撞配置。AI 在线调用与 UE 工具接口已完成。每栋实际网格预览在 exports/medieval_*_v006.png，导入报告在 Saved/MedievalIntegration/v006_import.json。

专属设计代码位于 medieval_identities.py，并嵌入 HIP；塔楼和连桥继续复用 v003 构造函数。维护脚本 build_medieval_v006.py 会在重建前备份已保存 v006；import_medieval_v006.py 遇到已存在资产会停止以保护编辑。
